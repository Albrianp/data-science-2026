## Kesimpulan Umum

Perjalanan belajar Data Science selama 13 pertemuan ini membentuk alur yang runtut, dimulai dari fondasi pemrograman hingga penerapan model machine learning dan deep learning:

**Pertemuan 1** memperkenalkan dasar-dasar Python di lingkungan Google Colab — variabel, tipe data, struktur kontrol, dan fungsi — sebagai bekal teknis sebelum masuk ke analisis data.

**Pertemuan 2** melatih eksplorasi dataset awal (EDA dasar): memahami struktur data, jumlah baris/kolom, serta mendeteksi missing value sebagai langkah pertama sebelum data diolah lebih lanjut.

**Pertemuan 3** memperdalam proses *data cleaning* secara menyeluruh — penghapusan duplikat, normalisasi string, imputasi missing value, penanganan outlier dengan metode IQR, hingga pengambilan data tambahan dari API eksternal menggunakan `requests`.

**Pertemuan 4** berfokus pada statistik deskriptif dan eksplorasi data lanjutan, membangun pemahaman terhadap distribusi, ukuran pemusatan, dan sebaran data sebagai dasar pengambilan keputusan analitis.

**Pertemuan 5** mengangkat visualisasi data menggunakan Matplotlib dan Seaborn untuk menyampaikan insight secara visual dan mudah dipahami.

**Pertemuan 6** menjembatani eksplorasi data ke tahap pemodelan, mencakup preprocessing untuk machine learning: penanganan missing value, encoding data kategorikal (One-Hot Encoding), train-test split dengan stratifikasi, dan feature scaling menggunakan StandardScaler — seluruhnya dipraktikkan pada dataset Titanic.

**Pertemuan 7** memasuki pemodelan prediktif melalui regresi, membangun model dasar untuk memprediksi nilai numerik dari data yang telah diproses.

**Pertemuan 9** memperkenalkan algoritma klasifikasi tahap pertama: Logistic Regression dan Decision Tree, dilengkapi evaluasi model menggunakan Confusion Matrix serta metrik Accuracy, Precision, Recall, dan F1-Score untuk menilai performa model secara komprehensif.

**Pertemuan 10** melanjutkan ke metode ensemble Random Forest serta strategi penanganan dataset tidak seimbang (*imbalanced dataset*), dipraktikkan langsung melalui studi kasus kelompok Customer Churn Prediction.

**Pertemuan 11** beralih ke ranah *unsupervised learning* melalui teknik clustering K-Means dan Hierarchical Clustering, serta Metode Elbow untuk menentukan jumlah cluster optimal tanpa label data.

**Pertemuan 12** membahas asosiasi data melalui Algoritma Apriori untuk Market Basket Analysis, serta konsep dasar sistem rekomendasi Collaborative Filtering dan Content-Based Filtering yang banyak diterapkan dalam e-commerce.

**Pertemuan 13** menutup rangkaian pembelajaran dengan pengenalan Deep Learning melalui Artificial Neural Network sederhana untuk klasifikasi data non-linear, serta penerapan NLP dasar menggunakan TF-IDF untuk analisis sentimen teks.

Secara keseluruhan, mata kuliah ini membangun pemahaman utuh terhadap siklus hidup proyek data science: mulai dari eksplorasi dan pembersihan data (Pertemuan 1–5), persiapan data untuk pemodelan (Pertemuan 6), pemodelan prediktif melalui regresi dan klasifikasi (Pertemuan 7, 9–10), teknik unsupervised learning dan sistem rekomendasi (Pertemuan 11–12), hingga pengenalan awal deep learning dan NLP (Pertemuan 13). Kombinasi teori dan praktik langsung di setiap pertemuan (kecuali Pertemuan 8 yang tidak tersedia) membantu membangun kompetensi end-to-end, dari data mentah hingga insight dan model yang siap digunakan.
